## ⚡ Quick Scan

- **Class block folder:** `kindergarten-justinger-kesys-pum`
- **Audience type:** Early elementary learners who benefit from visual modeling, predictable routines, and very small chunks of task time.
- **Design lens:** Use the biggest text, the fewest words, bright visual anchors, and repeated watch / do / check patterns.
- **Use this for:** pacing, partnering, slide design, tool setup, and support planning

## 👥 Recurring Support Needs

- Short, repeated directions with one concrete action at a time.
- High visual support for tools, buttons, turns, and cleanup routines.
- Co-regulation, calm pacing, and quick resets when frustration starts to rise.
- Motor-access support for touchpad, drag-and-drop, and device handling.

## ✅ What Helps This Class

- Use icon-first slides with one sentence and one action per slide.
- Model first, then do together, then release students in pairs or micro-groups.
- Keep teacher check-ins frequent and celebratory so persistence feels safe.

## ⚠️ What To Adjust Next

- Add more pause-and-check slides before independent work begins.
- Show fewer choices at once when tools or materials are new.

## 🎨 Presentation Rules For This Class

- Keep slides low-density and action-forward.
- Use repeated icons and colors so students can re-find the same kinds of information quickly.
- Make the help routine visible before students need it.
- Show what success looks like, not only what to do first.
