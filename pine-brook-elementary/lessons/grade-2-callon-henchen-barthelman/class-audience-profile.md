## ⚡ Quick Scan

- **Class block folder:** `grade-2-callon-henchen-barthelman`
- **Audience type:** Growing independent learners who can handle more tool variety when routines and choices stay well scaffolded.
- **Design lens:** Use chunked steps, explicit transitions, and visual examples that connect concept words to the exact task.
- **Use this for:** pacing, partnering, slide design, tool setup, and support planning

## 👥 Recurring Support Needs

- Visible routines for logging in, opening tools, and transitioning between digital and hands-on tasks.
- Language support for new CS vocabulary, especially when ideas are abstract like AI or classification.
- Modeling for how to start, what to do next, and how to ask for help productively.
- Support for sustaining attention through tool setup before the fun part of the lesson begins.

## ✅ What Helps This Class

- Keep a visible first / next / last sequence on slides all lesson long.
- Pair students strategically when one student can verbalize while another manipulates the tool.
- Show a finished example and a work-in-progress example so expectations feel reachable.

## ⚠️ What To Adjust Next

- Add more explicit bridge language from concept to activity so the why stays visible.
- Use more mid-lesson reflection checks to catch quiet confusion early.

## 🎨 Presentation Rules For This Class

- Keep slides low-density and action-forward.
- Use repeated icons and colors so students can re-find the same kinds of information quickly.
- Make the help routine visible before students need it.
- Show what success looks like, not only what to do first.
