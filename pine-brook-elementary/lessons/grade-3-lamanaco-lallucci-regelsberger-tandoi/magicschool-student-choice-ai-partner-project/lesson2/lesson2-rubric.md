# Lesson 2 Checkpoint Rubric

Use this rubric to assess Session 2: Build Step by Step.

| Category | Beginning | Developing | Meeting |
|---|---|---|---|
| Using the Plan to Build | K-2: Needs help finding the next part of the guide to use. 3-5: Does not yet use the guide to organize project work. | K-2: Uses the guide with support to start building. 3-5: Uses the guide for some project parts, but may skip around or need reminders. | K-2: Uses the guide with support to build project parts in order. 3-5: Uses the guide to build the project in a clear, organized way and stays focused on the plan. |
| Step-by-Step Execution | K-2: Needs frequent adult help to begin or continue the project. 3-5: Has difficulty turning the guide into actual project sections or slides. | K-2: Completes some parts with reminders and support. 3-5: Builds some sections successfully, but still needs prompts to keep going or finish in sequence. | K-2: Builds project parts with support and can show what was completed. 3-5: Builds 2 to 3 clear sections from the guide and works steadily through the steps. |
| CS Accuracy and Connection | K-2: Needs help explaining how the project connects to technology or computing. 3-5: The project drifts away from the CS topic or includes unclear connections. | K-2: Can show a simple technology connection with support. 3-5: The project includes a CS connection, but some sections need stronger explanation or correction. | K-2: Can explain a simple connection between the topic and computing. 3-5: The project stays connected to computer science, technology, AI, digital safety, or problem-solving throughout the built sections. |
| Responsible and Safe AI Use | K-2: Needs repeated reminders not to share private information and not to copy everything from AI. 3-5: Uses AI unsafely or relies on AI output without checking it. | K-2: Follows safety rules with reminders. 3-5: Usually follows safety rules and sometimes checks whether AI output fits the project. | K-2: Uses AI safely with teacher support and can say one rule. 3-5: Uses AI safely, checks AI output against the guide, and explains what the student kept or changed. |
| Readiness for Lesson 3 | K-2: Has very limited project progress and is not yet ready to revise. 3-5: The project has little visible progress or no clear next step. | K-2: Has part of the project built and can say what comes next. 3-5: The project has some built sections and a partial next-step plan, but still needs clarification. | K-2: Has enough progress to continue and improve in the next lesson. 3-5: Has visible project progress, knows what still needs work, and is ready for Lesson 3 revision and finishing. |
