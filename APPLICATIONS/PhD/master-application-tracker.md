# Master Application Tracker

Last updated: 2026-05-31

This is the working source of truth for research, fellowship, and PhD applications in the RESEARCH repository.

## Core rules

1. Check this file before giving application or deadline advice.
2. Keep submitted items separate from active tasks.
3. Every new opportunity must include source URL, deadline, status, fee status, and next action.
4. Submitted applications must be marked `submitted / monitor`.
5. Reviewed or skipped items must be moved out of the active queue.
6. Any opportunity with a required application-related payment must be marked `not applicable / fee` unless Piter later overrides this rule.

## Status labels

- `submitted / monitor`
- `active / build`
- `active / verify`
- `reviewed / skipped`
- `reviewed / no action`
- `not applicable / fee`
- `calendar`
- `monitor`
