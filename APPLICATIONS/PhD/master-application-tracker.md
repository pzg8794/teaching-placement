# Master Application Tracker

Last updated: 2026-05-31

This is the working source of truth for research, fellowship, and PhD applications in the RESEARCH repository.

## How to use this tracker

1. Check this file before giving any application/deadline advice.
2. Do not rely on scattered chat notes when this file exists.
3. After an application is submitted, update the row status to `submitted / monitor`, add the submission date, and record the confirmation/application ID when available.
4. If an opportunity is reviewed and intentionally skipped, move it to `reviewed / skipped` or `reviewed / no action` so it stops appearing as an active deadline.
5. Keep active next deadlines separate from submitted/monitor-only items.
6. Add every new opportunity with official source URL, deadline, timezone if known, country/route, fit, status, materials needed, and next action.

Status vocabulary:

- `submitted / monitor`: submitted; only monitor receipts, emails, or portal updates.
- `active / build`: not submitted; materials need to be built.
- `active / verify`: possible opportunity; eligibility or source details must be checked.
- `reviewed / skipped`: intentionally not applying.
- `reviewed / no action`: reviewed but not worth further work unless strategy changes.
- `calendar`: future deadline; not active yet.
- `monitor`: recurring scan or future call.
