# Placement storage map

## Local source

`second-placement/` is the working source. The curated SBTE share is `second-placement/shared-with-sbte/`.

## GitHub

The public repository is `pzg8794/teaching-placement`, branch `teaching_placement_shared`. GitHub receives public-safe planning, original classroom materials, and indexes. Raw transcripts, student information, packet photographs, and licensed source pages are excluded.

## Google Drive

The existing second-placement folder is the public-safe Drive mirror. Its current inherited setting is anyone with the link as reader, so it receives only broadly shareable materials. Restricted SBTE-only practice keys are not placed there.

## OneDrive

The OneDrive folder `Teaching Placement Shared with SBTE` is the restricted collaboration surface for two subject-based compartments: `Introduction to Marketing - Blocks 1 and 5` and `Principles and Tools of Business - Blocks 4 and 7`. It is shared directly with the SBTE rather than made public.

## Update rule

Update canonical local files first. Copy only current approved versions into the SBTE staging directory, then synchronize the public-safe subset to GitHub and Google Drive and the full curated staging directory to the restricted OneDrive share. Verify names, item counts, and permissions after each update.
