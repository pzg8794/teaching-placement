### 39-minute sequence

| Time | Display / teacher move | Student evidence | If energy or time is low |

| 0:10–0:14 | Introduce Teams as the communication and handoff space | Students can locate the course Team | Project and narrate; students point instead of clicking |
| 0:14–0:19 | Create the `Marketing` folder | A visible Marketing folder | Model only if devices are slow |

| 0:23–0:29 | Download the approved file, move it out of Downloads, and rename it | File is stored in the correct Marketing subfolder | Complete the download and move only; defer renaming |

| 0:37–0:39 | Exit check | “My file is in ___; AutoSave is ___; Turn in means ___.” | Ask for a show of hands at each checkpoint |

### Exact short opening

“Today is our setup day. First we will finish our class expectations. Then we will make a Marketing folder, learn where our files belong, and see how Teams is used to receive and turn in work. We are not starting Chapter 1 notes until Monday.”

### Non-negotiable workflow

1. Download the approved file.
2. Move it from `Downloads` into the correct Marketing subfolder.
3. Rename it using the SBTE-approved convention.
4. Open it **from the Marketing folder**.
5. Check whether AutoSave is on before editing.
6. Complete the work in Word, not inside Teams.
7. Upload the saved file from the Marketing folder when an assignment is actually ready for **Turn in**.

## Repeatable routine for the week

1. Students read the agenda as they enter.
2. Run one short chapter-connected brain teaser while taking attendance.
3. Discuss the starter for no more than three to five minutes unless the discussion is genuinely useful and relevant.
4. Teach two to four notes slides.
5. Read two to three pages and connect details back to the notes.
6. Build the vocabulary cards reached in that day’s reading; reveal the term or definition after the picture prompt.
7. Complete one aligned review item while the content is fresh.
8. Record the exact stopping point for the next class.

### Time record

These figures are teacher-planning evidence, not a pace target for students.

### Issues students are likely to hit

- The book’s save location may not match the district’s Microsoft 365 interface.
- A file left in Downloads is easy to lose and may not be the copy later uploaded to Teams.
- Closing before checking AutoSave or explicitly saving can lose work.
- Lesson 1.4 depends on retrieving the correct Lesson 1.3 file, so filenames and folders matter.
- Exporting to PDF is a separate action from saving the editable Word document.
- Fast finishers do not establish the correct whole-class pace; monitor and extend the block if needed.

### Improvement to make before students begin

Project the actual district interface and pause at four checkpoints: **correct folder, correct filename, AutoSave state, and final file type**. Say where each button is in the current interface instead of relying only on the printed screenshot.
