# Teaching Placement Workspace

This repository now uses two canonical placement boundaries:

- `first-placement/` — Spring 2026 teaching placement and its historical index.
- `second-placement/` — Fall 2026 teaching placement beginning September 8, 2026.

## Canonical rule

New work must be filed under the placement it belongs to. Do not add new Fall 2026 material to the repository root or to the first-placement archive.

The repository root still contains legacy Spring 2026 files and directories that predate this split. They remain temporarily as a compatibility layer so existing links and references are not broken. `first-placement/README.md` is the index for those historical paths. New first-placement archival cleanup should move or mirror material only after link/provenance review.

## Transcript privacy

Raw Plaud/course/placement transcripts belong in each placement's local/private `transcripts/private/` directory and are excluded from Git. Only privacy-reviewed, de-identified transcript-derived material may be committed under `transcripts/de-identified/`.
