# Teaching Placement Workspace

This Git repository is the **public-safe navigation and status layer** for two
teaching placements. It is not the storage location for raw or sensitive
placement evidence.

It uses two canonical placement boundaries:

- `first-placement/` — Spring 2026 teaching placement and its historical index.
- [`second-placement/MASTER-TODO.md`](second-placement/MASTER-TODO.md) — Fall 2026 Grade 6–12 placement master beginning September 8, 2026.

## Canonical rule

New work must be filed under the placement it belongs to. Do not add new Fall 2026 material to the repository root or to the first-placement archive.

The repository root still contains legacy Spring 2026 files and directories that predate this split. They remain temporarily as a compatibility layer so existing links and references are not broken. `first-placement/README.md` is the index for those historical paths. New first-placement archival cleanup should move or mirror material only after link/provenance review.

## Evidence and privacy boundary

Git may contain public-safe indexes, de-identified action summaries, lesson
materials cleared for sharing, and links back to authoritative private sources.
Original email bodies, contact details, signed forms, credentials, identifiable
student/school records, and other sensitive evidence must remain in the
authenticated mailbox, an approved private Drive location, or an ignored local
directory. Gmail message/thread IDs may be recorded as private-source locators;
they are not substitutes for the original messages.

## Transcript privacy

Raw Plaud/course/placement transcripts belong in each placement's local/private `transcripts/private/` directory and are excluded from Git. Only privacy-reviewed, de-identified transcript-derived material may be committed under `transcripts/de-identified/`.
