## Useful Takeaways

- `📚 Research pacing:` read and summarize papers steadily instead of batching them late.
- `👥 Advisor coordination:` ask early about target conferences and overall direction.
- `🧩 Version control:` learn branches, pull requests, and merge-conflict resolution because those are baseline professional workflows.
- `📝 Writing workflow:` Overleaf can be tied to Git when a document has many revisions or multiple contributors.
