## 🧠 How To Use This Workbook For Better Lessons

### ✅ What Is Expected

Use the workbook to identify:

- the grade-level topic progression
- the named standards
- the learning targets already written
- special education supports already anticipated
- the formal resources the lessons should build from

### ✅ What Was Achieved

Use the transcript-linked packet map plus lesson files to document:

- which packet was actually taught
- which transcript notes support it
- which standards were visibly enacted
- what students practiced, built, discussed, or debugged

### ⚠️ What Needs Improvement

Look for places where:

- the workbook names a lesson but there is no strong packet yet
- the standards are broad but the actual lesson evidence is thin
- the formal resource is named but not actually integrated into the lesson packet
- inclusion supports exist in the workbook but are not made visible in the lesson docs

### 🛠️ How To Improve

- pull the workbook standards and learning targets directly into lesson packets
- use the listed formal resource as the base lesson source
- use transcript evidence to prove what really happened
- compare the packet against the workbook’s special education considerations
- revise the lesson so the documented packet matches both the curriculum map and real classroom evidence

## 🧩 Support Sheets Worth Using Actively

### ♿ SWD Considerations

This sheet gives strong practical support ideas that should be pulled directly into lesson packets:

- clear, simple language
- visual supports
- predictable routines
- breaking tasks into smaller steps
- hands-on materials
- extra processing time
- positive reinforcement
- modeling expected behaviors
- flexible pacing
- backup plans to reduce downtime
- collaboration with special education staff
- collaboration with teaching assistants and aides

### 💡 Additional Future Ideas

- Kindergarten bracelet patterning
- Grade 2 communities Sphero project
- Grade 3 marine life / Google Vids / QR code unit
- inquiry and design-thinking extensions

This can help identify **next-step lesson packets** that are not yet built.

### 🧰 Additional Resources

This sheet is a resource bank for future enrichment. It includes:

- videos
- websites
- lesson plan libraries
- books
- design-thinking prompts
- Minecraft notes

This is useful when a current packet needs better formal grounding.
