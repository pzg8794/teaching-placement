\begin{block}{Core claim}
\large Students can use AI meaningfully when the lesson structure keeps their voice, choices, and thinking at the center.
\end{block}
\end{frame}

\begin{frame}{What problem am I trying to solve?}
\bigidea{Students were excited by AI tools, but excitement alone did not guarantee thoughtful, independent learning.}

\vspace{0.2cm}
\begin{columns}[T]
  \column{0.48\textwidth}
  \begin{block}{What I saw in placement}
  \begin{itemize}
    \item strong curiosity about AI
    \item high engagement with digital tools
    \item students moving quickly to whatever the tool produced
  \end{itemize}
  \end{block}

  \column{0.48\textwidth}
  \begin{block}{What worried me}
  \begin{itemize}
    \item tool navigation overshadowing learning
    \item copying without checking
    \item uneven independence
    \item students losing ownership of ideas
  \end{itemize}
  \end{block}
\end{columns}
\end{frame}

\begin{frame}{Why this matters in EDU442}
\begin{itemize}
  \item EDU442 asks us to turn course ideas about race, class, gender, disability, and equity into a usable practice artifact.
  \item In my placement, inclusive teaching often meant balancing \textbf{support} with \textbf{independence}.
  \item That same tension appeared in AI lessons:
  \begin{itemize}
    \item students needed structure to access the tool
    \item but too much teacher rescue reduced agency
  \end{itemize}
  \item This project grew from that question: \textbf{How do I teach AI in a way that supports diverse learners without reproducing inequity or replacing their thinking?}
\end{itemize}
\end{frame}

\begin{frame}{My impacting practice artifact}
\begin{block}{Artifact}
\Large MagicSchool Student-Choice AI Partner Project
\end{block}

\vspace{0.25cm}
\begin{itemize}
  \item A reusable three-session lesson sequence for Grades 3--5
  \item Students choose a topic, use AI as a supervised thinking partner, and create a product
  \item Product choices include a slideshow, poster, booklet, or simple site
  \item The instructional goal is not just ``use AI''
  \item The real goal is: \textbf{plan, check, revise, explain, and stay the author of your own work}
\end{itemize}
\end{frame}

\begin{frame}{What makes it neurodivergent-friendly and inclusive?}
\begin{columns}[T]
  \column{0.48\textwidth}
  \begin{block}{Neurodivergent-friendly design}
  \begin{itemize}
    \item chunked directions
    \item visible routines
    \item reduced typing load
    \item prompt starters
    \item checkpoints before overload grows
  \end{itemize}
  \end{block}

  \column{0.48\textwidth}
  \begin{block}{Inclusive design}
  \begin{itemize}
    \item flexible product choices
    \item teacher think-alouds
    \item partner roles
    \item drawing, dictation, or oral rehearsal before typing
    \item support for access without removing ownership
  \end{itemize}
  \end{block}
\end{columns}

\vspace{0.2cm}
\begin{alertblock}{Key principle}
The tool should adapt to the learner. The learner should not have to adapt completely to the tool.
\end{alertblock}
\end{frame}

\begin{frame}{Why AI can support learning well}
\begin{itemize}
  \item AI can help students brainstorm, narrow a topic, and organize ideas.
  \item It can reduce the blank-page problem for students who struggle to get started.
  \item It can support clearer explanations, simpler language, and step-by-step planning.
  \item For some learners, especially students who need structure or language support, AI can function as a low-stakes thought partner.
\end{itemize}

\vspace{0.25cm}
\begin{block}{But only if...}
\large students are taught to question, revise, and explain rather than copy and submit.
\end{block}
\end{frame}

\begin{frame}{What the classroom evidence taught me}
\begin{columns}[T]
  \column{0.48\textwidth}
  \begin{block}{What worked}
  \begin{itemize}
    \item student choice increased buy-in
    \item copyable prompts reduced friction
    \item teacher modeling made safer use possible
    \item partner talk lowered language load
  \end{itemize}
  \end{block}

  \column{0.48\textwidth}
  \begin{block}{What needed adjustment}
  \begin{itemize}
    \item logging in and tab management took time
    \item some students treated AI output as final
    \item some topics were too broad
    \item success criteria had to remain visible all lesson
  \end{itemize}
  \end{block}
\end{columns}
\end{frame}

\begin{frame}{The deeper instructional shift}
\bigidea{I am not teaching students to get answers from AI. I am teaching students how to think with AI while keeping authorship, judgment, and responsibility.}

\vspace{0.2cm}
\begin{itemize}
  \item This is a digital-literacy goal.
  \item This is an inclusion goal.
  \item This is also a future-ready goal for classrooms where AI will increasingly be present.
\end{itemize}
\end{frame}

\begin{frame}{Why this counts as impacting practice}
\begin{itemize}
  \item It is grounded in real teaching-placement experience, not a hypothetical future classroom.
  \item It responds to a recurring instructional need I actually observed.
  \item It produces a reusable artifact that another teacher could adapt.
  \item It connects educational technology, special education thinking, and responsible instruction.
  \item It moves from reflection to design:
  \begin{itemize}
    \item What did I see?
    \item What problem kept repeating?
    \item What practical structure could improve it?
  \end{itemize}
\end{itemize}
\end{frame}

\begin{frame}{What I would refine next}
\begin{itemize}
  \item collect student artifacts from each product type
  \item save stronger classroom evidence from future reteaching
  \item refine timing for login and setup routines
  \item build a teacher-facing checklist for prompt quality, topic fit, and independence
  \item adapt a lighter version for younger grades or higher-support learners
\end{itemize}
\end{frame}

\begin{frame}{Closing}
\begin{block}{Final takeaway}
\Large My impacting practice project argues that AI belongs in elementary learning only when it is taught through visible routines, inclusive scaffolds, and student ownership.
\end{block}

\vspace{0.25cm}
\begin{itemize}
  \item AI should be a learning partner, not a shortcut.
  \item Support should open access, not replace thinking.
  \item Inclusive structure is what makes responsible AI use possible.
\end{itemize}
\end{frame}
