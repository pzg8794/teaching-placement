\section*{UDL and Inclusion Supports}
\subsection*{Multiple Representation}
\begin{itemize}[leftmargin=*]
\item Model both the physical route and the digital page side by side.
\item Use arrows, icons, and color-coded path markers.
\item Keep page expectations low-text and high-visual when needed.
\end{itemize}

\subsection*{Multiple Action / Expression}
\begin{itemize}[leftmargin=*]
\item Allow students to demonstrate understanding through route setup, oral recording, drawing, or typed text.
\item Use partner roles such as driver, builder, recorder, and checker.
\item Offer sentence stems for explaining what the robot should do.
\end{itemize}

\subsection*{Multiple Engagement}
\begin{itemize}[leftmargin=*]
\item Combine movement and storytelling so students can enter through either robotics or communication.
\item Celebrate each successful route or finished page as a milestone.
\item Use authentic audience language: this page helps someone else understand the robot.
\end{itemize}

\section*{How to Improve Inclusion Next Time}
\begin{itemize}[leftmargin=*]
\item Add a one-page route planner students complete before touching the robot.
\item Prepare a low-text book template with image-first boxes.
\item Collect one exemplar page and one exemplar route photo in \texttt{artifacts/}.
\item Build in a final comparison step: what the robot did versus what the page says it did.
\end{itemize}

\section*{Teacher Moves / Script / Routines}
\begin{itemize}[leftmargin=*]
\item Model the route physically before opening the digital explanation task.
\item Name one debugging move students must try before asking for help.
\item Pause to show a strong example of a page that clearly explains the robot action.
\item Close with a short share-out of what changed after debugging.
\end{itemize}

\section*{Common Errors and Debugging}
\begin{itemize}[leftmargin=*]
\item Students may focus on the robot only and skip the explanation side.
\item Students may make the digital page decorative but not informative.
\item Pair work can drift if roles are not explicit.
\end{itemize}

\section*{Extensions and Simplifications}
\begin{itemize}[leftmargin=*]
\item Extension: ask students to create a second page about how they fixed a mistake.
\item Simplification: provide a preset route and ask students only to explain it.
\item Extension: add a “predict before test” step for each route.
\end{itemize}
